# hamr

For operating hamr on a user's behalf, read [the operator guide](src/audiobook/agent_guide.md) or use `hamr agent guide`. Discover the installed command contract with `hamr agent capabilities`.

For release work, use the checked source tree. Keep private books, job state, research, source audio candidates and user reports out of the public repository and archives.

Put listening tests that need user input in the workspace's shared local inbox. Use `tools/performance_review.py inbox DIRECTORY add PACK` and send the common inbox URL. Read saved picks before requesting another audition. Complete each entry after acting on its pick and recording the result. Keep the original audio, picks, and qualification evidence local.
