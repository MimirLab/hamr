DjVuLibre 3.5.30.1 (GPL-2.0-or-later), separate Hamr DjVu worker:
https://deb.debian.org/debian/pool/main/d/djvulibre/djvulibre_3.5.30.1.orig.tar.xz
SHA-256 e38eae20427fa7b17787482f1dd00e88b173913d59f5f8bc5175ee40a02872f2
The corresponding Hamr worker source is tools/intake_djvu.cc. Build DjVuLibre
with --disable-shared --enable-static --disable-desktopfiles --disable-xmltools.
Compile the worker with -O2 -static-libgcc -static-libstdc++ and link the
resulting libdjvulibre.a with -pthread. The Linux builds bind stock glibc
and process original files locally.

XPS page renderer for Linux x86-64, requiring glibc 2.36 or later:
GNOME libgxps 0.3.2, built by Debian as libgxps-utils and libgxps2
version 0.3.2-2+b1. Its worker is the unmodified xpstopng.
https://deb.debian.org/debian/pool/main/libg/libgxps/
The asset's notices directory contains licenses, Debian package pins,
and exact checksums for the corresponding source and patch archives.
The same pins are available in tools/intake_xps_runtime.json in the sdist.

The libarchive 3.8.11 source and checksum are pinned in that manifest.
Unpack its source and extract the listed sysroot packages with their
paths intact. Ensure that the sysroot path lib64/ld-linux-x86-64.so.2
is a relative symlink to ../lib/x86_64-linux-gnu/ld-linux-x86-64.so.2.
Run tools/build_xps_libarchive.sh to build the shared library with the
ZIP decompression dependencies. The release used GCC 16.2.1, CMake 4.4.4,
and GNU binutils 2.47. Run tools/build_intake_xps.py with the pinned
binary packages, resulting library, upstream COPYING file, and desired
archive path to assemble the resident runtime.
