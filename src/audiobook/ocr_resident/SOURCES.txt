Linux x86-64 uses GLIBC 2.34 or later. The build includes static PNG and zlib
from Ubuntu 22.04 (libpng 1.6.37, zlib 1.2.11). The Windows x64 worker
statically includes libpng 1.6.59 and zlib 1.3.2.
https://github.com/pnggroup/libpng/tree/v1.6.59
https://zlib.net/fossils/zlib-1.3.2.tar.gz

Both workers take PNG input from Hamr's own raster pipeline. The Windows
source build adjusts the case of the WinSock import library in Tesseract's
CMake file. See the build commands shipped in the source distribution.
